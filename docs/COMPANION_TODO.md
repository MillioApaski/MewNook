## 聊天表情与性能实现

- 对新交付的助手台词做保守的本地措辞匹配，输出 `happy/caring/curious/calm/neutral` 和受限强度；这不是模型情感识别。只绑定已有原画眉毛、猫耳、头部和单一眼睑参数。摸头姿态优先，口型仍由台词播放控制。
- 普通、流式台词都参与联动；播放结束、停止生成、关闭聊天、错误后释放。打开历史不触发。测试页提供台词输入，点击聊天表情可切换检查。
- PWA 从安装时预缓存所有测试资源和四套画面，改为只预缓存应用外壳；干净构建从约 7293 KiB 降至约 355 KiB（约减少 95%）。运行时代码、画面采用网络优先并提供离线缓存回退，避免稳定 URL 锁住旧代码/图片；固定版本模型和 WASM 按需缓存。更新模型时必须同步更新资源 URL 的版本标记。
- 手机（宽度不超过 680）DPR 上限 1，原上限为 1.25，对原先达到上限的设备减少 36% 画布像素；渲染上限 30 fps，桌面仍为 60 fps。隐藏页面会取消渲染 RAF 和参数计时器，恢复时重新启动，不补跑后台帧。
- 新增 `scripts/check-chat-performance.mjs`：检查表情参数差异、结束释放、历史不重播、错误、流式取消、未访问资源不预缓存、受控页面离线再次打开、手机 DPR/帧率限制，以及后台暂停/恢复。该检查与全部 `tests/*.test.mjs` 已接入 CI。
- `assets/inochi/v4/validation/chat-performance-report.json` 记录本地软件 WebGL 测量环境、模型就绪耗时、资源体积、实际帧数及断言。它是可复现的本地基线，不代表真实网络或手机帧率。
