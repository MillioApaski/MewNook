# MewNook · Inochi2D runtime experiment

## Scope and non-goals

This is an opt-in **genuine Inochi2D** WebGL2/WASM experiment with a third-party
rigged sample model. It does NOT generate a Cubism file, does NOT represent a
finished custom MewNook character, and does NOT replace default PNG artwork.

## Run

```bash
npm install
npm run prepare:inochi
npm run dev
```

Open Settings > Virtual Room > Inochi2D Test Mode.
The download is ~18 MB for the rig and ~1 MB for the runtime, but is only
requested by the client when the user enables testing.
WebGL2 is required. The original PNG layer remains visible until the model
successfully loads and is restored on failure.

Only runtime behavior is verified by the default CI build; final WebGL visual
quality needs a real-browser screenshot/regression test.

## Original minimal MewNook rig (new)

`public/inochi2d-test/models/MewNook-test.inx` is now generated by
`scripts/build-mewnook-inx.py` from the MewNook project's existing
`public/assets/rooms/day/character.webp` illustration (not from Aka).

The generator writes a real INP1-compatible `.inx` binary:
`TRNSRTS\0` magic, serialized puppet JSON, and PNG texture blobs.
It contains 8 distinct textured Part meshes and 8 adjustable parameters
(two blinks, two ear rotations, tail sway, breathing, head look and mouth).
The resting image is based on disjoint masks. This is a rudimentary rig;
automatic polygons can leave hard boundaries during large deformations.
There are no professionally animated clips yet.

The new full-portrait artwork made in October 2026 has separately been
prepared as a 14-layer editable OpenRaster file, but it is not yet the
source of this generated test model. Reconcile the two art sources when
moving to a refined hand-rigged version.

Chromium WebGL2 CI now loads `MewNook-test.inx`, not Aka. The
third-party Aka model remains bundled solely for historical/compatibility
testing and keeps its CC BY attribution. The test model is generated
from preexisting artwork inside this MewNook repository.
