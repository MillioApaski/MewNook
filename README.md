# MewNook 🐾

**A cozy, local-first anime companion workspace.** 和小猫一起专注、听雨、整理日程。

MewNook 是一个可安装的 PWA，目标是在浏览器中提供沉浸式陪伴工作空间。当前版本是可交互的第一阶段原型，**没有账户、没有强制 AI 服务，也不需要付费后端**。

## 已实现（第一阶段）

**v0.2 UI 改版：** 主页现在为全屏虚拟房间与角色，番茄钟/日程/统计/设置/音乐/环境音通过悬浮工具栏打开抽屉；底部为 Galgame 式台词框，可展开 AI 对话。不再采用常驻三栏 dashboard。白天、黄昏、雨天和夜间均已接入仓库内置的分层 WebP 插画。


- 🌱 番茄钟：专注、短休息、长休息、自定义时长、暂停、继续、刷新后恢复、会话记录。
- 📋 日程与任务：按天查看、创建、完成、删除、关联当前专注任务、重要标记。
- 📊 统计：当天专注时长、七日柱状图、历史专注记录。
- 🐈 猫娘原型：根据专注/休息/夜晚切换表情与姿势的 **原创 SVG 占位角色**。
- 🌦️ 虚拟房间：随浏览器当地时间自动切换昼夜，并按 Open-Meteo 天气模拟雨景；支持手动切换。
- 🎧 声音：浏览器本地合成雨声、风声、柔和底噪，可以分别调整音量；选择本地音频播放。
- 💬 AI：可编辑人格、实时番茄钟上下文、SSE 流式回复（支持关掉）、可取消/重试、有限历史上下文、手动记忆摘要、默认关闭的主动问候；自带 URL/模型/Key（BYOK）。
- 💾 本地保存、导入/导出 JSON 备份，PWA 安装及 Cloudflare Workers Static Assets 配置。

**角色图片说明：** 之前生成的六格图片是带场景的预览图，不适合直接叠加。现阶段使用 SVG 角色占位，待六张统一且透明背景的立绘制作完成后替换。尚未接入 Live2D。

## 内置四种天气与时段插画（无需导入）

白天、黄昏、雨天、夜间场景分别位于 `public/assets/rooms/day/`、`public/assets/rooms/sunset/`、`public/assets/rooms/rain/`、`public/assets/rooms/night/`，每套包含 `background.webp`、`character.webp`、`foreground.webp` 三张 WebP。渲染顺序为背景 → 猫娘人物 → 桌面前景遮挡 → 悬浮 UI。所有素材均内置于仓库，不需要手动导入或额外 API。

在 **设置 → 虚拟房间 → 场景** 选择「晴朗白昼」「日落黄昏」「雨天小屋」「安静夜晚」查看插画；选择「自动」则由本地时间和天气决定。图层共用 1672×941 虚拟画布和固定人物锚点，切换时间段无需改变前端布局。生成式插画在家具造型和布置上可能存在细微差异，属于后续美术校对工作。

## 自动对话与专注动作

对话框默认只显示约 6.5 秒，然后自动隐藏；点击右侧「聊天」会展开完整对话，直至手动关闭。猫娘产生新回复、开始专注、专注结束或休息结束时会短暂显示提示，不会一直遮挡桌面。

专注时会自动切换至仓库内置的透明看书或打字立绘（`public/assets/companion/reading.webp`、`typing.webp`）。默认为自由专注时看书、关联任务时打字，也可以在番茄钟的「猫娘专注动作」中指定。

## 本地开发

需要 Node.js 22+。

```bash
npm install
npm run dev
```

本地打开 Vite 输出的地址。生产构建：

```bash
npm run build
npm run preview
```

## Cloudflare Workers 部署

无需 AI Gateway、D1 或 R2。前端通过 Workers Static Assets 提供服务。

```bash
npm install
npx wrangler login
npm run deploy
```

或者在 Cloudflare 的 Workers 项目中连接此 GitHub 仓库，设置构建命令 `npm run build` 和输出目录 `dist`（以 Cloudflare 当前的 Git 集成界面为准）。部署脚本和 Worker 静态资源设置见 `wrangler.jsonc`。

> Cloudflare 账户、GitHub 自动部署授权和自定义域名必须由仓库所有者配置；仓库提交本身不等于线上已经部署。

## AI 配置及安全

进入 **设置 → 自定义 AI API**，可以编辑「小猫同学 · 人格预设」并恢复默认。默认人格包含自然中文、克制口癖、尊重边界、不假装拥有现实感知与操作能力、专注时简短回应和休息时自然闲聊。点击猫娘使用本地台词，**不会消耗 API 额度**，即使休息计时未自动开始仍使用休息台词。

发送 AI 消息时会附带当前专注/休息阶段、剩余时间、关联任务及用户称呼，这些信息与历史对话一起发送到所选服务商。

进入 **设置 → 自定义 AI API**：

- Base URL：如 `https://api.example.com/v1`
- 模型：服务商给出的实际模型 ID
- API Key：仅保存到浏览器 `sessionStorage`，不进入备份、D1、Worker Secrets 或 Git 仓库
- 人格预设：保存在浏览器设置并进入 JSON 备份，最多 5000 字符；留空时使用默认预设

浏览器直接调用用户填写的 API，**服务商必须允许浏览器跨域 (CORS)**；目前不提供代理。限制为 HTTPS URL，仅允许回环地址使用 HTTP。请勿填写不可信的 API 域名。打开开发者工具或安装恶意扩展仍有机会泄漏前端密钥，敏感 Key 最好创建权限和额度受限的专用凭据。

对话默认本地保存在 `localStorage`，在聊天中避免输入不希望长期留在浏览器的数据。API 服务商会收到本次调用的聊天内容。

## Phase 3C：AI 陪伴增强

- **流式生成**：OpenAI 兼容 `/chat/completions` 的 SSE 回复逐步显示，也可在设置中关闭流式。模型服务需允许浏览器 CORS；某些非标准兼容接口可能需要关闭流式。默认有每次 600 个最大输出 Token、12 条最近对话上限，且最多取最近 12000 字符；非绝对账单额度限制。
- **中断与重试**：聊天生成时可停止；出错或停止后可重试上一条消息，不会在历史中重复追加提问。已完成的回复才计入对话历史；未完成的部分只临时显示。
- **记忆**：在设置中自行编辑和清空本地记忆摘要，或**主动点击**“AI 整理聊天”使用一次独立 API 请求整理。无后台自动摘要；摘要及对话保留在本地并进入 JSON 备份，请勿录入敏感隐私信息。
- **主动搭话**：默认关闭，开启后只在网页处于前台、非专注且未展开聊天时运行；本地问候不花 Token。另有**独立明确开关**允许由 AI 生成问候，单条最多 120 输出 Token，每日设定 1–6 次，失败不自动重试；多标签页或多设备不保证严格合并额度。
- 项目不提供云同步、后台任务或服务端定时轮询；关闭网页后不会主动发消息。

## 数据、媒体与限制

- 任务、设置、统计、对话历史：浏览器本地 `localStorage`；不会跨设备同步，清理网站数据可能造成丢失。
- 音乐文件：用户通过文件选择器在当前会话播放，不上传云端，也不会在刷新后自动重新打开。
- 环境音：由 Web Audio API 在本地实时合成，属于原型音效，不是授权音轨。
- 天气：使用 [Open-Meteo](https://open-meteo.com/)，需遵守其非商业使用及署名条件。
- 番茄钟：基于绝对时间计算，减少后台节流引起的误差；**浏览器关闭后不会持续发送系统通知**。
- PWA：具备静态离线缓存，但 AI 与实时天气必须联网。桌面悬浮窗需要后续独立桌面应用。
- 尚无账户、D1 云同步、第三方在线音乐接入、语音 TTS、正式立绘资产和 Live2D。

计划请见 [docs/ROADMAP.md](docs/ROADMAP.md)。

## Inochi2D 实验模式（v3）

打开 **设置 → 虚拟房间 → Inochi2D 实验模式**，即可将原有场景人物 PNG 替换成透明 WebGL2 Inochi2D 模型；未启用或最终加载失败时仍使用原来 PNG。v3 加载异常会先尝试自动回退 v2。独立测试页面：`/inochi2d-test/smoke.html`，默认 v3，使用 `?model=v2` 可对比上一版本。

- 原创**工程绑定**：`public/inochi2d-test/models/MewNook-v3.inx`（约 2.3 MB），从仓库已有白天人物立绘生成的 13 个部件、18 个参数。包括可独立眨眼的眼部、闭眼眼线、微笑/困倦/聊天，以及 3 组可变形发束和 1 组尾巴网格。
- **验证**：Chromium WebGL2 正常加载、眨眼以及四组原生 `deform` 参数的画面变化，都由真正的 Chrome 截图逐帧对比验证。已经移除所有 `transform.t.x` 兼容位移兜底，头发和尾巴确实由**网格顶点**驱动。
- **修复**：Inox2D 按 `zsort` 从大到小绘制，新增眼睛和发束必须使用较小（负）层级；纹理必须输出 **premultiplied alpha** 才能与 Inox2D 的 `GL_ONE / GL_ONE_MINUS_SRC_ALPHA` 混合匹配。两项均有自动测试。
- 模型生成：`python scripts/build-mewnook-v2.py` 然后 `python scripts/build-mewnook-v3.py`，配套 `check-mewnook-v2.py`、`check-mewnook-v3.py` 与 `scripts/diagnose-inochi-v3.mjs`。
- Web 运行时及旧版 Aka 样例由 [AITuber OnAir](https://github.com/shinshin86/aituber-onair) 提供，固定哈希下载且在仓库内保留依赖许可。Aka 作者 seagetch，CC BY 4.0，仅作兼容对照，不作为 MewNook 原创模型。
- **局限**：当前仍然用扁平原画半自动抽取图层，没有对隐藏部分全面手工补画，也不是由 Inochi Creator 艺术家逐网格绑定的完成品。此前生成的另一套角色分层素材尚未替换成正式工程源图；大幅度头部转向、书本/打字动作仍待制作。默认仍然为静态 PNG，以免初次打开网站就加载模型。
