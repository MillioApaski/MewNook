# 头侧到肩部连接发片源工程

当前模型：GPT-6 Sol。

从原画拆出两侧连接发片，排除此前前发、蝴蝶结、胸前发片和衣服的选区。修正误选的衣服折线，补全发片内部被颜色筛选漏掉的孔洞；已有前景发束造成的遮挡留给原图层。

运行 `prepare-v4-connectors.py`、`separate-v4-connectors.py` 重建，依赖 Pillow、NumPy、opencv-python-headless。图像编辑输入保存在 `inputs/`：原裁图与两侧标色指南用于隐藏底稿；独立发片和隐藏边缘指南用于不透明发色纹理。内置 imagegen 只供被遮挡的底稿和 5 像素搭接余量，不替换可见发片核心。

`MewNook-v4-connector-source.ora` 继承 v9 全部工作层，加入连接发片。默认显示完整原图参考，隐藏工作组是实际拆层结果。图层工程经 CRC、所有图层 PNG 解码及序列化重组核对，先在内存完成后原子保存。

检查前发三档 × 左右连接发片各五档，共 75 种组合；连接发片根部固定，向肩部渐增至 ±4 像素，预乘透明度插值。虹膜/嘴部核心不变；连接发片单独移动时脸和衣服前景 RGB 不变，范围外已有工作图可见 RGBA 不变。`face-clothing-occlusion-mask.png` 须随每帧应用，不能直接把未裁切素材作为最终显示。

可见核心保留原 RGB，具体数量见 `validation.json`。端点接根、剩余细卷发、完整头发及全局头部变形仍需整体验收；静态位移不代表真实绑定。未接入测试页。
