# MewNook v4 面部分层源文件 v1

这是**面部源素材审阅工程**，不是完成的全角色拆层、Inochi Creator 工程或可直接绑定的模型。没有修改网站或替换现有 INX。

## 查看

- `MewNook-v4-face-source-v1.ora`：可用 Krita、GIMP 等支持 OpenRaster 的软件打开。画布 1122×1402，图层保留原图坐标。
- `face-comparison.png`：从左到右为原画、闭眼、张嘴、困倦。
- `preview-*.png`：仅替换指定面部区域的完整立绘。
- 独立 PNG 已裁去透明空白，放置偏移量在 `manifest.json` 的 `offset` 中。

## 图层

- `original-remainder`：移除指定面部区域后的原画；头发、身体、衣服、椅子、尾巴仍在这一层，并没有完成独立拆分。
- `skin-underpaint`：原位补画的五官下方皮肤，来自 AI 图像编辑；没有使用肤色几何遮片。该层默认隐藏：原图五官像素有半透明，默认叠底会改变原始 alpha。检查遮挡区域或准备绑定时再按需开启。
- `left/right-iris`：直接从原画选择的虹膜像素，保留原高光和瞳孔。
- `left/right-upper-lashes`、`left/right-lower-lid`：按颜色及位置选择的原画睫毛和眼线。仍需手工精修边缘，并非专业完成的 alpha matte。
- `left/right-eye-surround`：原画眼白与周边过渡像素，**包括部分皮肤过渡**，不是独立补画完整的眼白。
- `brow-left/right`、`mouth-neutral`：原画眉毛和闭嘴素材。
- `paint-closed`、`paint-talking`、`paint-sleepy`：对齐后的 AI 表情补画，默认隐藏。开启一个对应图层可以查看该表情；不要同时开启闭眼和困倦。

补画采用上一轮通过原立绘图像编辑得到的三个表情，不使用带肤色晕边的独立五官生成试作，也不使用未配准的秃头或刘海试作。

## 已验证

1. 实际打开导出的 ORA 图层数据，从下到上重组后，原画全部 740243 个可见像素的 RGBA 数值与源图一致。
2. 表情图仅在记录的眼部或嘴部选择范围内改变像素；范围以外的 RGBA 与原图一致。
3. PNG 为真实 RGBA，独立图层的裁剪尺寸、原画坐标和补画配准矩阵保存在 manifest 中。

这些检查证明数据与位置关系，不代表美术、精细抠图或绑定完成。
