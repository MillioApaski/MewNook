# MewNook v4 面部源工程 · 第二轮修订

本轮只处理面部素材，**不是已完成的全角色拆层、可绑定模型或网站更新**。

## 查看方式

使用 Krita、GIMP 等支持 OpenRaster 的软件打开 `MewNook-v4-face-source-v2.ora`，画布仍为 1122×1402。

- `v1 SOURCE REFERENCE`：16 个原参考图层，默认显示。实际读取导出 ORA 重组后，原图全部可见 RGBA 像素保持一致。
- `v2 WORKING MATERIALS`：11 个新工作图层，默认隐藏。**这是独立素材集合，不是已组装的脸部替换组。** 单独查看时可隐藏参考组，再逐项显示一个工作层；不要把所有虹膜版本同时叠在一起。
- `matte-comparison.png`、`light-background-check.png`：深、浅背景上的边缘检查。
- `iris-underpaint-check.png`：可见原虹膜与隐藏部分补画的对照。
- `preview-sclera.png`：眼白补画在指定区域内的效果；区域外保留原图。
- `forehead-patch-extent.png`：仅示意额头补画覆盖范围。**不是已经分离并移走刘海的最终效果图**，原刘海与发卡尚未完成精确抠图。

独立 PNG 的坐标偏移在 `manifest.json` 中；文件仅裁去透明边，不代表应该自动居中放置。

## 新工作图层

左右各 5 层：

1. `iris-visible`：重新沿原画可见虹膜选区取像素，补回 v1 漏掉的下方浅色区域，去除选区边缘明显混入的眼白、皮肤及上睫毛。
2. `iris-underpaint`：采用独立虹膜图像补画填充隐藏区域，配准至原虹膜范围；选定原画可见区的 RGBA 原样保留。**接缝和实际移动效果仍待检查**。
3. `upper-lashes-matte`：从原画上睫毛推导柔和 alpha 边缘，使用皮肤底稿估计解除边缘混色。边缘 RGB 与 alpha 会改变，不应称为逐像素未修改的抠图。
4. `lower-lid-matte`：处理下眼线选区并排除混入的蓝色虹膜碎片。原画下眼线本身有断续；没有用程序补画一条新线。
5. `sclera-underpaint`：通过图像编辑补出的眼白底面，保留上眼睑阴影。当前边缘仍包括局部皮肤／眼睑过渡，需要进一步精修遮罩。

另有 `forehead-underpaint`：补出刘海后方的额头、眉眼表面，作为隐藏区域候选。

## 素材来源与处理边界

- 原画参考组完全保留。
- 虹膜可见区使用原画像素；隐藏区使用 AI 图像编辑补画，没有程序绘制替代眼睛。
- 补画输入保存在 `paint-inputs/`。整张立绘补画只取面部需要的局部，其他部位的生成变化不会写回原图。
- 整张立绘的虹膜补画试作没有完全移除上睫毛，已弃用；采用的补画输入是独立虹膜版本。
- 睫毛边缘去底色依赖估计的皮肤底色，仍可能有细小偏差；深浅背景检查不是专业美术验收。
- 从源图复制的可见像素、数学推导的 matte 和生成式补画，在 manifest 中分别标记。

## 已验证

- 实际导出的 ORA 包可读，包含 16 个参考层 + 11 个工作层。
- 默认参考组重组后的可见 RGBA 与原图一致。
- 虹膜补画中保留的原画可见选区，RGBA 与原图选区一致。
- 局部预览的选区之外，RGBA 与原图一致。
- 深、浅背景上检查了新工作素材。
