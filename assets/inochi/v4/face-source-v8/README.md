# 闭眼眼周接缝修复

由 `python scripts/prepare-v4-blink-source.py` 导出。原画睫毛、虹膜及九级眼睑几何沿用已有素材，张眼帧与 face-source-v6 像素一致。

旧版在闭眼时以统一 RGB 偏移的补画皮肤覆盖整块眼槽，周围腮红和肤色梯度不能衔接，形成硬边。现在只重建眼睛与睫毛原先占用的区域：从实际周围皮肤取样，排除头发、眼白和睫毛颜色，解调和插值填补不可见皮肤；其余区域保留原张眼素材。外圈皮肤颜色与张眼帧一致，实际闭眼睫毛不参与边缘混合，眼槽覆盖仍不透明，避免露出旧眼白。

- `*-blink-*.png`：两眼各九个运行时关键帧。
- `*-skin-support-full.png`：修正后的肤色底稿。
- `*-closed-lash-full.png`、`*-upper-lid-full.png`、`*-lower-lid-full.png`：原画材质。
- `MewNook-v4-blink-source.ora`：保留原画坐标的可编辑脸部工程。
- `blink-motion-check.png`：开合状态对照。
- `manifest.json`：槽位、原画材质信息及边缘回归数据。

导出器验证：原张眼帧不变、各帧覆盖范围一致、完整闭眼无旧深色眼部残影。两眼共 286 个非眼线边缘皮肤像素在全部九帧中与张眼帧完全一致；该局部指标用于捕获色块硬边，不能替代实际视觉验收。
