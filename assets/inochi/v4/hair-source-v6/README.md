# 丝带旁发束、右侧蝴蝶结与细白发源工程

当前模型：GPT-6 Sol。

沿原画分离三个部件：向外挑出的白色发束、右侧深蓝蝴蝶结、位于蝴蝶结前方的细白发。主体彩色像素来自原画；生成图仅用于遮挡区补画，不替换整张立绘或原画部件轮廓。长侧发、后发、左侧蝴蝶结及完整模型均未完成。

## 重建与工程

```sh
python3 scripts/prepare-v4-ribbon-flick.py
python3 scripts/repair-v4-ribbon-flick.py
python3 scripts/separate-v4-right-bow.py
python3 scripts/check-v4-ribbon-assembly.py
```

需要 Pillow、NumPy、opencv-python-headless。`manifest.json` 记录各工作图层在原始 1122×1402 画布中的偏移。

`MewNook-v4-ribbon-joint-source.ora` 为当前自包含可编辑工程。默认显示原图参考；隐藏 `JOINT CHECK — long side and back hair incomplete` 组包含前阶段发冠、呆毛、四片前发、发卡、眉毛、眼尾，以及新增白发束、细白发和右侧蝴蝶结。查看工作组时关闭原图参考。导出验证 ZIP CRC、默认参考可见像素以及实际序列化工作组的中立状态合成结果，再原子替换。

## 补画与配准

内置 imagegen 的三次局部编辑均保留输入和结果：

1. `inputs/flick-hidden-generated.png`：从原画小裁图移除标出的白发束，在原蓝布位置续画丝带折面、根部续画浅色侧发，保持其余发丝。生成图的细节改变使特征配准只有 4 个内点，未采用该拟合；改用保留区域的平移 ECC，相关度约 0.9824，平移约 `(0.219,0.039)` 原图像素。只消费原发束窄选区。
2. `inputs/bow-hidden-generated.png`：根据原画及标色指南移除整个深蓝蝴蝶结，续画其下白紫色头发，发外保持透明，保留前方白发束与细白发。与原画保留部分配准有 30 个内点，中位误差约 0.259 原图像素。
3. `inputs/bow-and-flick-hidden-generated.png`：在第 2 张补画结果上移除横向白发束，续画竖向底发，保留细白发。这一步避免联合底稿仍带有旧白发束。通过父图配准有 133 个内点，中位误差约 0.104 原图像素，再与第 2 步矩阵连接。两个误差分别记录，不将它们误当成最终绝对精度。

`bow-under-flick-painted.png` 把第 1 步补出的蓝布放回独立蝴蝶结材料中，填补原白发束遮挡处。其他原画蓝布主体保持原样。蝴蝶结边缘用附近原画蓝色与实际底稿估计透明度，避免把与白发混合的浅色边缘带进蓝布材料。

## 已检查的范围

- 小发束 5 个上下弯曲位置，主体 604 个核心像素 RGB 与原图一致；深浅背景检查。工作层半透明度超过 0.5 的像素中，深蓝污染计数为 0。
- 蝴蝶结 6675 个蓝色核心像素 RGB 保持原样；工作层半透明度超过 0.5 的像素中，浅白污染计数为 0。这两个计数是针对已知串色问题的检查，不代表所有边缘已美术验收。
- 细白发拆出 142 个原图不透明白色核心像素；其中根部以外 114 个可见核心在全部联合组合中保持原 RGB。小发束移动时可以自然遮住细白发根部。
- 前发/发冠/呆毛三档联动 × 蝴蝶结三档 × 小发束三档，共 27 种联合组合。原虹膜、固定眼尾核心和头部范围外可见 RGBA 保持原样。并未声称检查了所有部件参数的完整笛卡尔积。

`bow-flick-joint-motion.png` 显示头部参数为 0 时的九种蝴蝶结与小发束组合；`flick-matte-check.png`、`right-bow-matte-check.png`、`fine-strand-matte-check.png` 为深浅底素材检查。`right-bow-motion-candidate.png` 是提取阶段诊断，最终遮挡以联合工程为准。

剩余：长侧发与后发的完整轮廓、隐藏区补画，左侧蝴蝶结，结合完整头发复查根部遮挡；随后仍有眼口精修、正坐姿与真正网格绑定。此目录只做静态源素材检查，未接入测试页。
