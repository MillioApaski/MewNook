# 两侧外侧长发与后发源工程

当前模型：GPT-6 Sol。

本阶段拆出绕过手臂、垂到坐垫旁的两大组原画长发。可见发束来自原图；补画仅消费头发后方的坐垫及衣袖、蝴蝶结、裙子后方的隐藏头发窄带。尚未完成全部头发，不接入 `/inochi2d-test/smoke`。

## 重建

```sh
python3 scripts/prepare-v4-outer-hair.py
python3 scripts/separate-v4-outer-hair.py
```

依赖 Pillow、NumPy、opencv-python-headless。补画输入保存在 `inputs/`；生成补画指南可运行 `prepare-v4-outer-fill.py`，不自动调用图像生成服务。隐藏头发用内置 imagegen 按原发色、卷曲与阴影续画，要求填满指南标记并保留外轮廓、位置和透明背景，不新增身体或衣服。实际可见部分仍从原画提取。

## 工程与遮挡

`MewNook-v4-outer-hair-source.ora` 默认显示原图参考；隐藏工作组继承胸前长发版图层，新增两侧外发及背景底稿。关闭参考后查看工作组。完整部件 PNG 保留衣服下的隐藏发丝；每次移动后必须应用 `foreground-body-occlusion-mask.png`，让衣袖、手与裙子继续遮住头发。ORA 的静态中立层已应用该遮挡，不能直接当作完成的动作模型。

从原图颜色与区域约束分离头发，保护原衣服与猫尾连接区，剔除远离主体的孤立碎片。两侧分别有 63689 / 57308 个核心像素 RGB 保留原值；抗锯齿边缘另算透明度，不声明整个部件逐像素一致。底稿坐垫补画按保留的躯干部件配准，180 / 302 内点，中位误差约 0.676、P95 约 1.463 原图像素。

## 验证与限制

左右各 -8/-4/0/+4/+8，共 25 个静态位移组合。检查原衣服前景 RGB、修改范围外既有工作图可见 RGBA、默认原图参考及序列化 ORA 工作组。位移采用预乘透明度插值。`validation.json` 记录隐藏补画覆盖率，`*-missing-hidden-fill-mask.png` 记录缺口；覆盖不足不得视作该阶段美术验收通过。

早期补画只覆盖约 80%、91%/94% 的所需隐藏位移区。新补画的右片发生约 15% 横向比例变化，配准保护拒绝消费该片；左片对齐通过，仅消费其隐藏窄带，并结合此前对齐通过的补画。裙摆旁发梢的 17 / 115 个缺口通过额外不透明隐藏纹理底稿补齐，仅取此前补画缺失、且原本被衣服遮挡的像素；该底稿不定义新轮廓，不宣称其纹理通过原画特征配准。当前左右 ±8 像素小范围检查所需隐藏余量覆盖均为 100%，缺口遮罩为空。完整头发仍未验收。保留不足的输入供追溯。源工程仍待完整轮廓、猫尾及坐垫边界检查，耳下到肩部的连接发片拆分、耳根遮挡与细卷发整理。之后仍有眼口、正坐姿、网格、物理与实际动作。
