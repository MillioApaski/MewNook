# 原画眼白与虹膜边缘修复

当前模型：GPT-6 Sol。

继承连接发片联合工程，沿用原画虹膜及 v2 已有隐藏虹膜/眼白补画。可见核心仍来自原画，没有新画替代眼睛图形。

运行 `python3 scripts/repair-v4-eye-materials.py` 重建。依赖 Pillow、NumPy、opencv-python-headless。原有生成式补画及来源分别保存在 `face-source-v1`、`face-source-v2`；本版不重新调用图像生成。

修复旧颜色分类把虹膜深色外缘误分到睫毛的缺陷。真实眼裂边界附近保留睫毛，将眼内深色虹膜边缘交还给移动虹膜；眼白底稿清除旧虹膜完整足迹，避免瞳孔移动后留下短线。虹膜核心保留原 RGB；抗锯齿边缘按实际眼白背景解混并限制最小透明度，隐藏弧仅使用已有补画。

左右各 25 个共用注视方向（±2 原图像素）检查：中立状态可见虹膜 RGB 平均误差为 0，眼区外的已有工作图可见 RGBA 不变，眼白底稿中指定虹膜邻域的旧深色残留为 0。深色残留检查只针对虹膜邻域，不把真实眼线误报为残留。`gaze-motion-check.png` 是源图静态检查，不是运行时动作。

`MewNook-v4-eye-source.ora` 默认显示原图参考，隐藏工作组包含实际眼白支撑层、原画虹膜及继承的全部头发工作层。固定眼尾归还眼部支撑层，避免同一眼尾留在独立固定层里。眼区/眼裂/上下眼睑区域及虹膜核心遮罩分别保存，供后续闭眼素材使用。

本版完成眼白与虹膜的小范围源素材检查。自然闭眼、眉毛/面部/口型、全局头部变形和实际绑定仍未完成，未接入测试页。
