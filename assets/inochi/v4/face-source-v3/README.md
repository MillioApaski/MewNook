# MewNook v4 面部源工程 · 第三轮静态检查

这是原画拆层与补画的工作文件，尚未完成全角色拆层或模型绑定，未接入网站。

## 本轮可检查内容

打开 MewNook-v4-face-source-v3.ora：33 个图层。原画参考组默认显示；第二轮素材和第三轮检查素材默认隐藏。请单独检查工作层，不要全部同时叠加。独立 PNG 的放置偏移见 manifest.json。

- gaze-contact-sheet.png：虹膜水平 -2、0、+2 像素的三张静态重组。使用原画可见虹膜、隐藏区补画、补画眼白和原画睫毛。眼睑开口遮罩限制虹膜范围，不是移动整个眼睛截图。三帧均无虹膜越出遮罩，眼部选区以外 RGBA 不变。这只验证裁剪，不能代替美术验收。
- fringe-contact-sheet.png：前发片段的同幅度位移检查。范围仅为横跨额头的部分发丝，不含完整发冠、发卡、侧发。原画核心像素保留，边缘 alpha 和颜色从原图与补画底稿推导。
- 前发检查未通过：眉毛与发丝交界仍有断线、原轮廓残留；不能用于摸头或摆头动作。边缘颜色保守处理后，细小色点减少，但不能据此称为完成抠图。
- fringe-original-selection / remainder 是精确保留原像素的参考分区，不是可直接绑定的最终透明边缘。

## 验证及限制

实际读取导出 ORA 的嵌套图层重组，默认显示结果与原画全部可见 RGBA 像素一致。33 层数量已验证。前发工作重组的零位 RGB 平均误差约 1.104/255，不能宣称逐像素一致。

眼白遮罩目前为二值检查遮罩；眼缘、虹膜补画接缝仍需人工精修。下一步要解决刘海与眉毛相交位置的遮挡关系，再完成头发分组、隐藏区域补画和实际绑定。当前没有提供正坐姿、眨眼、聊天、困倦或摸头的可用模型。
